O que é Equação do 1º Grau?

A equação do 1º grau é uma igualdade matemática que envolve uma incógnita (geralmente representada por x, y ou z) elevada ao expoente 1. A forma padrão é:

ax + b = 0

Onde a é o coeficiente (número que multiplica o x) e b é o termo independente (número sozinho). O objetivo é encontrar o valor de x que torna a igualdade verdadeira.

Perguntas Frequentes

O que é a Raiz da Equação?

A raiz da equação é o valor numérico que, ao substituir a incógnita (x), torna a igualdade verdadeira. Por exemplo, em 2x + 4 = 0, a raiz é -2, pois 2(-2) + 4 = 0.

E se o coeficiente 'a' for zero?

Se a = 0 e b = 0, temos 0x + 0 = 0. Isso é uma Equação Indeterminada, pois qualquer número serve como resposta (infinitas soluções).
Se a = 0 e b ≠ 0, temos 0x + 5 = 0. Isso é uma Equação Impossível, pois 0 é sempre igual a 0, nunca a 5.

Como resolver na cabeça?

Pense: "O que multiplicado por 'a' dá o negativo de 'b'?". Ex: 3x + 9 = 0. Pense: "Quanto vezes 3 dá -9?". A resposta é -3.

🧠 Dica de Estudo

Sempre faça a prova real! Depois de encontrar o valor de X, coloque ele de volta na equação original e veja se o resultado é zero. Se não for zero, reveja suas contas.
